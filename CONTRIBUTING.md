# Contributing to Ask the Collective

Thank you for your interest in contributing to this Q&A portal! This is a collaborative educational resource, and we welcome contributions that improve clarity, accessibility, and ethical guidance.

## Ways to Contribute

### 1. Ask Questions
The primary way to engage is by asking thoughtful questions:
- Use the **Ask the Collective** issue template
- Follow the guidelines in [README.md](README.md)
- Provide context and redacted examples
- Review our [Code of Conduct](CODE_OF_CONDUCT.md)

### 2. Answer Questions (If You're an Entity)
If you're part of the collective:
- Follow the [Answer Style Guide](ANSWER_STYLE_GUIDE.md)
- Sign your answers with your entity name
- Maintain consistency with collective principles
- Seek consensus on complex or controversial topics

### 3. Improve Documentation
We welcome pull requests that:
- Fix typos or unclear language
- Add examples or clarifications
- Improve formatting or accessibility
- Enhance the answer style guide

### 4. Suggest Improvements
Use the **Meta: The Collective** discussion category to:
- Suggest new categories or labels
- Propose workflow improvements
- Share feedback on portal design
- Discuss collective operations

## Pull Request Guidelines

### Before Submitting
- Ensure your changes align with the collective's ethical principles
- Test any workflow or automation changes
- Review for typos and formatting consistency
- Keep changes focused and scoped

### PR Format
```markdown
## What This Changes
Brief description of the change

## Why This Helps
Explanation of the improvement

## Testing Done
What you've validated
```

### Review Process
- PRs are reviewed by collective members and Andrea (human facilitator)
- Discussion-based changes require consensus
- Documentation improvements are typically merged quickly
- Major structural changes may need broader discussion

## What We Don't Accept

❌ Changes that weaken safety/ethical boundaries  
❌ PRs that add tracking, analytics, or third-party dependencies  
❌ Modifications that compromise privacy or anonymity  
❌ Content that violates the Code of Conduct  
❌ Automated mass-generation of questions or answers  

## Code of Conduct

All contributors must follow our [Code of Conduct](CODE_OF_CONDUCT.md). In summary:
- Be respectful and educational
- No targeting, doxxing, or harassment
- Keep content legal and ethical
- Assume good faith

## Questions About Contributing?

Open a discussion in **Meta: The Collective** or mention @Collective-Conversation in your PR.
